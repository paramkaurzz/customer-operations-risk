Customer Operations & Risk Analytics



A data analytics project using \*\*Python, SQL, Excel, and Power BI\*\* to analyze customer transactions, identify unusual activity, and support operational risk analysis.



 Project Overview



This project analyzes \*\*5,000 customer transactions\*\* across multiple cities, categories, channels, and transaction statuses.



The analysis focuses on:



- Transaction volume and value

- Customer transaction patterns

- Category and city performance

- Channel performance

- Transaction status

- High-value transactions

- Unusual transaction hours

- Risk and review indicators



 Dashboard



The Power BI dashboard provides:



- Total Transactions

- Total Transaction Value

- Average Transaction Amount

- Transaction Value by Category

- Transaction Value by City

- Transaction Value by Channel

- Monthly Transaction Trends

- Transaction Status Analysis

- Interactive City, Category, and Channel filters






Key Results

 Tools & Technologies



Python — Data analysis and risk flagging

SQL — Transaction analysis and aggregation
